# Validate OpenShell runtime on Linux agents

Validate the OpenShell supervisor and collector rollout on the Linux agent hosts after the first-class OpenShell support lands.

Required checks:
- Install or restart mac-openshell-supervisor and mac-openshell-collector on each required Linux agent.
- Confirm there is one active OpenShell sandbox per agent and that MAC/Hermes gateway, autonomous task executor, Hermes session children, and finalizer subprocesses share the same sandbox id.
- Run one autonomous task, one Hermes gateway-triggered session, and one deterministic finalizer.
- Trigger a denied filesystem or network attempt and confirm the denial appears in OpenShell logs, /action-events, dashboard Observability action feed, memory summary eligibility, and OTLP export.
