# Vendor a pinned, pruned Hermes runtime snapshot into the monorepo

**ADR 0001 stage 2.** Stop cloning pristine `NousResearch/hermes-agent` at
deploy time. Own a snapshot in `src/mac/_hermes/`.

The keel exists: `deploy/hermes/SNAPSHOT.md` (pin `b1a25404b`, include/exclude
manifests) and `scripts/vendor-hermes-snapshot.sh` (dry-run default, `--apply`
to write). This ticket is the deliberate, reviewed act of running it and
committing the result.

## Acceptance Criteria

- [x] Trace which `hermes_cli`/`skills`/`tools` modules are actually reachable
      from the gateway + agent runtime; prune the include manifest to those.
      Done via `scripts/trace-hermes-reachability.py` (394 reachable files);
      `SNAPSHOT.md` include/exclude + the vendor script arrays now reflect the
      measurement (added `plugins/`; confirmed broad prune set).
- [x] Runtime import trace (real `hermes -z` oneshot under `python -v` on rocky)
      validated the manifest: `plugins/` loads 273 files at runtime (dynamic;
      confirmed essential), `skills/` did NOT load in a basic oneshot (likely
      on-demand / from `HERMES_HOME`). Vendor the static∪runtime union.
- [x] `scripts/vendor-hermes-snapshot.sh --apply` vendors into `src/mac/_hermes/`
      with the three patches folded in and cruft excluded. Done (added `--from`
      to vendor from a local pinned checkout): 590 py files / 1225 total / 29M;
      all 3 patches applied clean; excludes pruned.
- [x] Merge dependency manifests: analyzed — **no conflicts**. Only 2 of
      Hermes's 16 core pins overlap mac (httpx, pyyaml), both within mac's
      ranges. Merge = mac deps + 14 Hermes pins + 2 tightened overlaps,
      `requires-python>=3.11`, provider extras stay lazy. Applied to
      `pyproject.toml` (core merge + `hermes-gateway` extra for platform deps).
- [x] Repo imports the vendored package; a smoke import test passes. Done:
      `mac.hermes_vendor.ensure_on_path()` + `tests/test_hermes_vendor.py`
      (leaf imports + `hermes_cli.runtime_provider`); full suite 653 green.
- [ ] Delete `deploy/hermes/*.patch` (now in-tree) and the clone-and-patch path
      in `deploy-mac-fleet.sh` is staged for removal in hu-04.
