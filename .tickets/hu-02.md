# Vendor a pinned, pruned Hermes runtime snapshot into the monorepo

**ADR 0001 stage 2.** Stop cloning pristine `NousResearch/hermes-agent` at
deploy time. Own a snapshot in `src/mac/_hermes/`.

The keel exists: `deploy/hermes/SNAPSHOT.md` (pin `b1a25404b`, include/exclude
manifests) and `scripts/vendor-hermes-snapshot.sh` (dry-run default, `--apply`
to write). This ticket is the deliberate, reviewed act of running it and
committing the result.

## Acceptance Criteria

- [x] Trace which `hermes_cli`/`skills`/`tools` modules are actually reachable
      from the gateway + agent runtime; prune the include manifest to those.
      Done via `scripts/trace-hermes-reachability.py` (394 reachable files);
      `SNAPSHOT.md` include/exclude + the vendor script arrays now reflect the
      measurement (added `plugins/`; confirmed broad prune set). Still TODO: a
      runtime import trace to validate `skills/` + lazy-loaded paths.
- [ ] `scripts/vendor-hermes-snapshot.sh --apply` vendors into `src/mac/_hermes/`
      with the three patches folded in and cruft excluded.
- [ ] Merge dependency manifests: adopt Hermes' **exact-pin** discipline; resolve
      conflicts with mac's loose ranges; set `requires-python>=3.11`.
- [ ] Repo imports the vendored package; a smoke import test passes.
- [ ] Delete `deploy/hermes/*.patch` (now in-tree) and the clone-and-patch path
      in `deploy-mac-fleet.sh` is staged for removal in hu-04.
