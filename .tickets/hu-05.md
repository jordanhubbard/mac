# Close the tokenhub dark spot: consume its decision feed (do NOT merge it)

**ADR 0001 stage 5.** TokenHub stays a separate Go service — it is mature infra
(Thompson-sampling router, AES-256-GCM/Argon2id vault, Temporal workflows) and a
Python rewrite would be the ACC "too complicated" failure. The actual problem is
that its routing decisions are invisible to the agent.

TokenHub already broadcasts routing events over an SSE event bus
(success/error/escalation/health/model-selection) and renders a live decision
feed in its admin UI. mac just doesn't consume it.

## Findings (this session)

Empirically confirmed the dark spot: with full hub access I could *not* readily
determine which of TokenHub's 305 models each agent's request used (API, admin
endpoints, and the 83M `tokenhub.sqlite` all resisted a simple read). TokenHub's
SSE bus lives at `/events` (`event: <type>\ndata: <json>`); the `Event` carries
`model_id`, `provider_id`, `reason`, `latency_ms`, `cost_usd`, tokens,
`error_class`, and — crucially — `api_key_name` + `request_id` for attribution.

## Acceptance Criteria

- [x] Consumer built + tested: `src/mac/tokenhub_feed.py` parses the SSE feed
      (`iter_sse_events`) and maps each event to a `tokenhub.route.*` /
      `tokenhub.provider.health_change` observation (`event_to_record`),
      secret-free, attributed to the agent via `api_key_name`. Streamer
      `stream_decisions()` (stdlib). `tests/test_tokenhub_feed.py` (9 tests).
- [x] Each routing decision maps to a `tokenhub.route.*` observation attributed
      to the agent (`api_key_name` → `subject_id`); records `reason` (thompson
      sample / failover / etc.), latency, cost, model, provider.
- [ ] **Runtime wiring**: run `stream_decisions` from a mac process (control-plane
      background thread or a dedicated service that POSTs to `/observability`),
      reading the events URL from config. Best validated against live TokenHub
      on the fleet.
- [ ] Surfaced in the dashboard's observability view (auto once events flow with
      `layer=tokenhub`; may add a dedicated provider-decisions panel).
