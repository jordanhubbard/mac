    v1.5.0 documentation and contribution audit¶

    Audited 2026-09-14 against the release candidate based on c55ea47ed3239d471132b414dc2f0d8a43cceeb0. Canonical ledger record: task_cc032b780f404f88bf19f4898b429b64.

    Scope and evidence limits¶

    The inventory below records a source anchor and changed/not-changed decision for every current document enumerated before this release pass. Generated references and executable book contracts are verified by the documentation gate. Operational runbooks were compared with their implementation and existing dated receipts; this audit does not claim to have re-executed every deployment, recovery drill, provider integration or native desktop workflow. Historical measurements remain historical, and proposed ADRs remain proposals. The release wheel and fleet cutover have separate acceptance requirements.

    Corrections cover PostgreSQL-only storage, explicit migrations, independent crash-observer Python, Hermes-specific gateway checks, current CLI verbs, the actual desktop bridge boundary, and validation before publication.
